¿Cómo se calcula?
  1. Frecuencia. Se cuentan los siniestros de cada una de las 60 combinaciones y se dividen entre el tiempo que esa combinación existe (la exposición). Sin esto, «despejado» siempre parecería lo más peligroso solo por ser lo más común. Se ajusta una regresión de Poisson.
  2. Gravedad. Entre los siniestros que ocurrieron, se ajusta una regresión logística que estima la probabilidad de que sean graves o mortales. Esta parte usa solo los datos, sin supuestos.
  3. Índice. Frecuencia relativa × gravedad relativa. 1,0× es el promedio de todas las condiciones.
  4. Intervalos. El «IC 95 %» es el rango donde, con los datos disponibles, está el valor real con 95 % de confianza. Si el promedio cae dentro del rango, el sistema no afirma que haya diferencia.

Exposición supuesto, no dato medido

Límites que conviene tener presentes

  • La frecuencia es relativa («veces el promedio»), no una probabilidad absoluta de sufrir un siniestro: para eso harían falta datos de tránsito (vehículos-kilómetro).
  • El modelo suma el efecto de cada factor por separado, sin interacciones. También estima combinaciones casi imposibles (lluvia fuerte con calzada seca); fíjese en cuántos casos reales las respaldan.
  • El clima y la calzada de este momento no se leen de ninguna fuente: se eligen a mano hasta conectar el IMN.
  • Es un modelo estadístico sencillo para orientar decisiones, no un sistema de predicción validado. Con datos reales conviene revisarlo con un especialista antes de apoyarse en él.
